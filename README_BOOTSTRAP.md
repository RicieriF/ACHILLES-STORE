# Outdoor Commerce Bootstrap

Files in this bootstrap package:

- `AGENTS.md`: persistent instructions for Codex.
- `PROJECT_SPEC.md`: product and architecture specification.
- `TASK_001_BOOTSTRAP.md`: first implementation mission.

## Recommended use
1. Create an empty GitHub repository.
2. Put these three files at repository root.
3. Connect/open that repository in Codex.
4. Give Codex the Task 001 prompt included below.
5. Review test/build output before proceeding to Task 002.

## Task 001 prompt
Read `AGENTS.md`, `PROJECT_SPEC.md`, and `TASK_001_BOOTSTRAP.md` in full.

Execute only TASK_001_BOOTSTRAP.md.

Do not implement automatic Alibaba purchasing or supplier payment.
Do not weaken tests or TypeScript strictness to make the build pass.
Use current officially supported package versions and verify compatibility before selecting the monorepo structure.

At completion, show:
- files/modules created
- architecture decisions
- commands run
- lint/typecheck/test/build results
- unresolved blockers
- next recommended task

Commit the completed Task 001 changes if your environment permits it.
